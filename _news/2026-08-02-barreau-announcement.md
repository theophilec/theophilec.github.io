I am giving a talk for lawyers and the public about AI and building agents from first principles at the Paris Bar Association (Barreau de Paris) on September 28th, 2026.

The goal of the talk to give solid technical intuition about how an LLM works, then using this intuition to understand how we can build agents with them. There will be a practical session on prompt engineering at the end of the talk.

I'll be reusing much of the content I created for a course on LLMs I've given since 2024 for an IT Masters Program at Mines Paris - PSL. That course lasts a day so shortening everything will be a challenge, and I'm happy to add a shorter version to my repertoire.

The practical session is always a hit, so we'll see how it goes with lawyers in the audience.
